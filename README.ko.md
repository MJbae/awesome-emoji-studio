## 아이디어가 이모티콘이 되기까지

- **표정과 동작을 풍성하게.** 캐릭터를 기획하고 45개의 이모티콘을 생성하세요.
- **마음에 들 때까지 다듬기.** 개별 이미지를 수정하고 배경 제거와 외곽선으로 마무리하세요.
- **다운로드까지 한곳에서.** 5개 언어로 제목과 태그를 만들고, LINE·카카오톡·Telegram·OGQ용 6가지 형식의 ZIP으로 내보내세요.

**브라우저에서도, 데스크톱 앱에서도.** 별도 서버를 구축할 필요가 없습니다. Gemini API 키가 필요하며, AI 요청은 Google로 직접 전송됩니다. 이미지 후처리와 ZIP 생성은 사용자의 기기에서 처리합니다.

## 내 컴퓨터에서 실행하기

Node.js 22.12 이상과 npm이 필요합니다.

```bash
git clone https://github.com/MJbae/awesome-emoji-studio.git
cd awesome-emoji-studio
npm install
npm run dev:web
```

데스크톱 앱은 마지막 명령어 대신 `npm run dev:electron`으로 실행하세요. 앱에서 Gemini API 키를 입력하면 됩니다.
