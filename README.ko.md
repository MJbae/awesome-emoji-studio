# Awesome Emoji Studio

**컨셉 하나로 시작하는 이모티콘 제작 파이프라인.**

제작 흐름은 [MJbae](https://github.com/MJbae)가 직접 설계했습니다. AI 단계에는 Gemini를 사용합니다.

[**라이브 데모 ↗**](https://awesome-emoji-studio.vercel.app) · [설계 살펴보기](docs/pipeline.md)

- **생성 전에 기획부터.** 시장과 디자인, 문화적 맥락을 고려해 제작 전략을 세웁니다.
- **캐릭터의 특징을 살려서.** 외형 명세로 표정과 동작을 기획하고, 공통 참고 이미지로 각 이모티콘을 생성합니다.
- **내보내기까지 하나의 흐름으로.** 이미지를 다듬고 제목과 태그를 만든 뒤, LINE·카카오톡·Telegram·OGQ용 파일로 묶습니다.

진행 중 결과를 확인하고 필요하면 다시 생성하세요.
