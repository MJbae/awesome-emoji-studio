- **先定方向，再生成。** 结合市场、美术与文化视角，制定创作策略。
- **沿用角色设定。** 根据角色细节规划表情，再用同一张参考图指导图片生成。
- **完成制作流程。** 处理图片、生成标题和标签，再打包为适用于 LINE、KakaoTalk、Telegram 和 OGQ 的文件。

你可以逐步查看结果，并按需重新生成。
