# Pipeline diagrams

The five `.mmd` files contain the reviewed, localized Mermaid source for the seven-stage UI workflow.

The SVGs were rendered with Mermaid 11.17.2 and `mermaid.config.json`. Desktop uses `flowchart LR`; the mobile version changes only that direction to `flowchart TB`. Both retain the same seven stages and six transitions.

The README uses a standard HTML `picture` element so narrow screens show a legible vertical flow and wider screens show the compact horizontal flow. The graphics use plain SVG text, with no scripts, external resources, or embedded HTML.
